# Alt原生镜头位置记录接收

新增可选v2事件native_camera_position，以及location.native_camera_telemetry快照。旧包保持原准入；新事件仍须先检查封存身份，再验证闭合清单、事件/图片SHA，退出时再次复验。不得直接导入Foresight源码或读取未闭合实战正文。

native_camera_review只接受alt_camera_position_v1：镜头XYZ、目标XY、由XY重算的yaw；目标Z/pitch/roll/FOV/引擎数据时间必须为空。原子性、请求归属、采集帧同步、投影校准、live_usable等声明必须为false。日志接收时间必须带时区，读取区间最多16KiB、SHA格式和有限数值校验；按下到可读候选间隔不得超750ms。候选快照仅在声明最近且年龄不超过500ms时允许带位置，否则不得保留候选。

新事件不能宣称应用投影、不能带frame_id，每run最多128项。报告单列原生位置事件数、完整相机0组及未验证边界，不混入现有定位/表面回执成功数，不按UTC凑帧、补目标高度或反推准确率。位置事件来源日志字节SHA目前仅作为生产端声明保留，分析端没有完整原日志，不宣称已独立核验其内容。

本轮合成事件通过Foresight真实记录器封包、Insights独立进程复验，闭合SHA一致；不是自然游戏或投影验收。真实单条Alt绑定、日志稳定性、相机内参和世界坐标→屏幕精度仍待验证。
