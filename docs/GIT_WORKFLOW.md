# Git 使用流程

每次开发先读本文件，再执行 `git status --short --branch`。工作区干净时才从 origin 快进更新；有改动先检查，不覆盖、不重置。

本仓库维护离线分析；dota2-helper 维护实时助手。两边只交换记录与数据包，不互相导入代码。通用数据契约按版本维护，不为同步方便复制整个项目。

提交前检查文件清单、运行相应离线检查并执行 `git diff --check`。不提交 config/*.local.json、凭据、用户记录、录像、第三方运行环境或生成报告。用户授权提交/推送后才执行；不强推共享分支。新功能分支默认 `codex/` 前缀。

源码迁移不等于授权公开个人记录、变更许可证或删除旧历史。历史目录保持只读；旧助手仓库和已交付EXE保留可恢复状态。
