# 按场次检查复盘资料

先执行交接，再生成报告：

```powershell
python tools/sync_helper_records.py --latest 3
python tools/review_helper_records.py
```

新报告写入本仓库 `diagnostics/record-readiness/<UTC时间>/REPORT.md` 和 `report.json`。仅使用本次交接索引选中的启动记录，不遍历全部历史、不解析录像、不启动游戏、不联网、不修改原记录。不需要运行EXE。

生成报告前重新核验交接包内容地址和全部来源指纹。来源变化时该包标记blocked，不沿用旧场次和数量；未闭合、失败或未建立包的启动记录保留等待/阻止状态。独立封存比赛继续由既有交接校验拒收。

按比赛号及本地会话列出本人GSI、经济、BP、小地图、画面、音频、帧率与进程性能的收尾状态和缺口。只将日志明确报告的比赛号行数，或明确比赛目录内的行数关联到本场；共享且未绑定的资料写“未确定”。同通道的多份记录分别保留，不以最后一份覆盖前面的记录。

日志总行数包括不同含义的事件，不能当作唯一截图数、成功识别数或准确率。经济部分另列observations/context/roster/buff日志明细。时间字段保留原名称，received_at不换称captured_at，启动级时间范围不伪称本场覆盖。GSI出现POST_GAME仅证明记录到了结束状态，不证明从开局到结束均有记录。

本工具是后续内容复查的输入清单，不生成装备正确率、视野真值或声音识别结论。音频未收尾先解决收尾矛盾；未绑定的小地图资料先做时间/场次对齐；缺少截图和独立录像对照时继续保留未知。
