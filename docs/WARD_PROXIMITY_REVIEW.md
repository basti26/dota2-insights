# 重复与邻近眼位复核

用户指定聚焦重复和很近的眼位，复用已完成解析的 manifest/wards，不重跑录像、不修改Pi或Foresight。原有地图独立核验门禁保持；本次仅描述原始坐标中的距离和时序，不发布效果排名或新游戏提示。

入口：`python tools/review_ward_proximity.py --folder <已完成单场目录> --folder <另一场目录> --output <新报告目录>`。

先查封存身份，再由 ward_reference_export.build 验证完整解析、footer 身份、正文 SHA 和数量。具有相同录像和眼位 SHA 且内容一致的同场重复导出只计一次。同场来源冲突和同包重复编号拒收，同坐标的独立编号仍分别计数。128/256/512 原始世界单位作为敏感性比较，按相同眼类型配对。未知阵营单列。

新版报告仅在同一个声明地图版本内做描述性跨局距离比较。缺少版本的场次各自保留，版本不同的场次分别计算。报告列出符合比较条件、版本不同和版本未知的场次对数。无可比场次时跨局邻近配对数为 `null`。地图版本不是从游戏版本或日期推定，记录里的相同声明也不认证实际地图落位。新版报告的示意图按场生成，多场报告用 `--match-id` 指定其中一场。

热点以真实落点为中心，只取直接半径内的点，不通过链式连接无限扩张。按涉及比赛数优先排序；多个邻域可能重叠，不累计作互斥区域。事件结束和同时存活按解析记录保留，缺结束时间不补零。配对可含非相邻复插，不当作独立补眼事件。
