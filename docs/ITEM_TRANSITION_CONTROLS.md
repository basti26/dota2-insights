## 入口

```powershell
python tools/sync_helper_records.py --latest 3
python tools/prepare_item_transition_review.py --latest 3 --output diagnostics/<新目录>
```

工具按独立equipment索引重新同步，逐包open_rows进入/退出复验。只在同一包/英雄/格位的相邻有效观测间找：记录为同物品、记录为另一物品、记录变空。前一格必须是本机保留目录价>=2000的known物品；180秒以上间隔、未知/缺格/重复格、无时区/乱序/重复时间均断链。不跨包猜身份或按UTC合局。

按英雄/格/前后记录标签/类型去重，先选择首次出现，再看图片分数；每种最多24例，可显式调整至60。完整对数、不同案例数及超预算省略数分开。目录价格只是挑样依据，不认证当前补丁。

再次从原始行取身份/状态/物品/行SHA并按原几何裁片，不接受外部编辑的正负标签。绑定原图SHA和源正文SHA；原文中途改变则不发布成功清单。缺图/错图/缺几何独立标不可用，不猜画面。原生空通道明确channel_has_observations=false，不当作没有识别错误。输出两个原格裁片、数值相似度、逐项HTML和来源证据；相似度不修改识别或金额。
