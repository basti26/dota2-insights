# 眼位时间、阵营与地图报告

本轮按用户“继续推进Insights”和真眼/假眼地图统计方向实现，不开游戏，不修改Foresight或Pi服务，不重解析历史录像。当前仍是描述性报告，不能称最佳眼位或效果已认证。

## 入口

```powershell
python tools/review_ward_phase_profile.py --folder <单场完成目录> --folder <另一场完成目录> --map <已有固定SHA地图.jpg> --output diagnostics/<新目录>

# 或直接读取已经去重的累计快照；不能与--folder混用。
python tools/review_ward_phase_profile.py --snapshot diagnostics/<累计>/snapshot.json --map <已有固定SHA地图.jpg> --output diagnostics/<新目录>
```

生成profile.json、可离线打开的自包含report.html与run-summary.json。不依赖外部CDN、在线地图或额外HTTP服务；地图、筛选与原始眼编号均在文件内。页面按来源组、开局前/每10分钟、天辉/夜魇、真眼/假眼切换。地图小点对应每次放置，编号/表格对应固定256世界单位直接邻域；可展开查看比赛号、比赛时间、原始坐标和结束类型。白圈是编号标记，不是视野范围。

## 统计口径

- 先查封存身份，使用现有build验证完整解析/身份/正文SHA/数量；额外要求source_unchanged_stat、replay_eof、有限正比赛时长和提取器指纹。时间/阵营/坐标缺失单列，不补零。
- 以解析器及适配器指纹、明确记录的游戏/地图元数据分组。版本未知继续显示未知，即便同组也不据此认证地图相同。
- 时间边界为左闭右开：600秒归10–20分钟；比赛结束时刻及之后不计入。打满区间的比赛才进分母，包括本区间没放眼的完整比赛。
- 没打满区间的眼位仍在地图显示为橙色空心点，仅供参考；观察到重复也不混入频率分子/分母。开局前独立参考，因开局前覆盖未认证，不提供完整区间频率。
- 同一场补眼多次只贡献1场支持，放置次数另列。按同阵营/同眼类型建邻域，不经邻接链扩张；邻域可能重叠，不能当互斥分区累计。结束类型只是解析器观测，不能直接当排眼成功率。
- 地图沿用已有固定SHA示意图及旧投影，不产生新的标定认证，不导出实时敌方隐藏位置或操作建议。
