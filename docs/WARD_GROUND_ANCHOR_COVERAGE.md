# 旧保存帧的地面圆环覆盖核查

2026-11-06。为确认三边加锚点试验是否遗漏可用地面证据，将此前预定选取的 8 帧扩展到同批 5 份闭合来源的全部合格保存帧。不采集新画面、不改变识别阈值。

## 来源与范围

先运行 sync_helper_records.py --latest 1；对原有 5 份 ward-camera 包分别执行 ward_camera_review.review，查封存身份、闭合状态、事件/图片 SHA 和容量，再读取事件。完成后再执行 review 核验来源未变。筛选为 location、存在原生保存图片/本人画面锚点/世界 XY、同帧坐标年龄 -1 至 2.5 秒、本人存活；每包按图片文件去重。共 80 张，占约 62.3 MiB。

本次只读取以上有限来源，不搜索全部历史录像。原始资料不改写，图片按 SHA 复制到 Insights 忽略目录 diagnostics/anchor-coverage-20261106。来源清单、图片 SHA、原生尺寸、原锚点和上下文保留于 samples.json；重复帧的去重范围是同一来源包，不能据此声称 80 个独立空间位置。

## 结果

Foresight 独立进程在全部 80 张图片上运行当前 self_screen_anchor，80 张均能重新形成血条推算锚点，但 ground_ring_anchor 全部返回 ring_unconfirmed，没有可用于这条圆环路径的测量候选。因此本批没有新的圆环约束平面，也没有新增可验证的三维相机。

这是现有算法在这些保存图片上的覆盖结果，不证明图中实际没有圆环，不是圆环检测准确率，也不代表整局所有帧。遮挡、颜色、选中单位、特效与 JPEG 均可能影响观测；未逐帧标注，不给这些原因分配计数。不能降低阈值直到出现候选后把它当独立真值。

Foresight project/diagnostics/anchor-coverage-20261106/probe.json 保留全部输出；只与 Insights 交换 JSON 和图片，不跨仓导入源码。图片和元数据读取前后复验，来源包进入/退出复验均通过。

## 当前边界

虚化眼继续可试用，现有自然对局记录已有 bar_rect、脚底估算依据、圆环候选/失败和同帧 GSI；这些字段无需再次添加。旧图缺少可靠的地面对应，不能凭更多拟合把完整重叠改为通过。

下一步应核对独立静态结构的地面定义，或分析后续自然对局保存的清晰地面点。无需用户专门开游戏，不新增取帧频率。生产算法与显示参数未改，本批不重复回归；完整重叠仍未完成。
