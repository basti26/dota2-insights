## 两个实验分开

1. 资产实体世界坐标 → 独立地图/截图像素：比较窗口、裁框与Y轴。固定同一对应集、有效内容框、九区划分及误差口径。
2. 录像Gem原始坐标 → 独立同一对象的资产/世界坐标：比较显式平移，单位是世界单位。不能借窗口拟合吸收平移，也不以像素拟合证明`-16384`。

世界点原值、Z与来源长期保留；实体origin与图标几何中心是否相同是待证事实。模型包围盒、声明minimap窗口、截图有效内容框各自保存，不能相互代替。

## 已落地的开发评估工具

`tools/evaluate_map.py`四个子命令：

- `prepare --prototype <原型包> --landmarks <已有实体导出目录> --output diagnostics/<新目录>`：核验原型收据、封存政策与原始导出SHA，从已有文本补提塔；生成候选池、三个固定窗口及缺标注的开发输入。不运行解码器、不读取游戏安装、不填写像素位置、不创建最终留出集。
- `windows --dataset <development.json> --models <models.json> --policy <policy.json> --output diagnostics/<新目录>`：同一输入比较所有窗口。只接受development角色；不拟合、不开放final验收。`sealed_final_sha256`仅是可空摘要，不是可读取路径。
- `translation --dataset <translation-pairs.json> --candidates <translation-candidates.json> --output diagnostics/<新目录>`：独立同对象直接坐标对比较。没有配对时输出insufficient_evidence，误差为空。
- `ward-impact --prototype <原型包> --models <models.json> --baseline <原绑定模型名称> --output diagnostics/<新目录>`：先按小清单检查封存锁，再复验原型文件。固定原始眼位和平移，比较各窗口的归一化显示位移；不改原绑定、不改历史包。

每次输出必须使用新目录，输入与执行源码SHA在前后复验，完成时写COMPLETE。原型旧包继续只读。跨地图身份/框架拒绝比较，明确来源地图不符的眼位拒收；来源未知只可诊断预览。图像版本单独记录为image_map_identity：现有巡图6966、世界资产6971，即使地图包相同，也不能把图像身份直接填写成6971。当前仅允许跨构建的缺标注候选清单；一旦提供像素标注，默认拒绝跨构建数值验收，等待显式兼容机制。

### 统一口径

图像位置必须是未经预测引导、独立确认的指定地标中心，保留图像SHA、原尺寸、有效内容框、世界XYZ/来源、确认来源和点定义。官方底图如果没有相应动态图标，就不能制造对应；可用已有冻结截图，不强求一张底图。

误差为有效内容框内的归一化二维距离乘1024，矩形框的X/Y分别按宽/高归一化。边界采用连续图像边定义；像素中心另有约定时需另设版本，不允许默默加半像素。

按候选之外固定的partition_bounds等分九区，所有模型共用。每个空间地标跨帧误差取中位数，再报告空间地标median/p95/max；同时保留逐帧误差与分布，不把30帧同一点当30个空间点。同XY改名不能增加点数；相同地标跨图的世界原点与来源必须一致。同图内容框必须一致。

暂用median≤4、p95≤10参考像素。每区至少3个不同位置才评价该区；不足显示insufficient_evidence，空分布为null。3点仍不是统计充分性的证明，只是当前开发阶段的最低门槛；p95采用nearest-rank，小样本会退化为最大值。任何已有足量区域超线，整体显示outside_provisional_limits；其他区域的证据缺口仍保留。全部区域在暂行线内也只叫within_provisional_limits，**不会输出正式P2通过**。政策内容和版本均记摘要，不看结果改阈值。

所有塔保守标记为historical_training_point，避免漏掉旧塔标定的训练重合；开发集可以诊断，不能充当最终独立验收点。图标身份不明确的无序集合残差沿用MAP_WINDOW_REVIEW的历史诊断口径，不自动转成此处的命名对应。

## 训练、开发验证与最终留出的后续纪律

先建立独立对应、按空间位置分组，再分train/development/final；同一物理位置的不同图/别名不跨组。旧塔训练点不能进入final。当前材料无法形成足量独立最终集，不凭空创建“已封存”清单。

未来final文件单独封存，开放前固定：候选模型/训练拟合产物、区域定义、政策、最终ID与来源清单的SHA。拟合与开发只读前两组。正式阈值在开启最终集前确认，而不是看最终分布后选择。

最终评估只执行冻结实验；失败后的模型改进必须使用新的独立最终集，旧集降为开发资料，不能改模型后反复利用同一最终集宣称通过。最终放行器尚未实现，当前工具刻意没有解封/正式通过入口。

## 接下来与边界

1. 用已有图片集中确认独立地标；图标缺失/遮挡/原点语义不符分别留空，不用模型投点指导标注。若要新资料，先按自动留证流程设计字段，只接收自然对局材料。
2. 有足量开发证据后再决定是否需要训练拟合窗口；不把所有窗口和平移做自由组合搜索。
3. 开发比较收敛后，补最终清单封存与一次性评估；工具的数值证据也只能认证指定来源/点定义/版本，不能认证碰撞高度、可插眼或游戏镜头。
4. 有独立眼位像素对照及录像地图身份后才能推进P3；现有显示位移报告不能顶替。
5. 收尾挂账：跨构建同地图包的显式兼容声明入口、ViewTransform旧无model兼容与统一归一化实现、构造/zoom的scale范围一致性。坐标结论尚未收敛，本轮不混改显示行为；默认身份拒绝策略保持。

P4自有浮层、P5游戏镜头配准、动态树木/砍树必要性、GNV位语义与VHCG高度均不在本轮完成范围。
