# 静态地图碰撞几何与声明地标

2026-11-05。继续虚拟地图P0/P1：本轮从本机标准地图实际解出碰撞三角网格，整理游戏声明的小地图边界和26个非塔地标。数据层可用性进一步明确，P2独立图像地标验证仍未通过；不改Foresight投影、不重新拟合真实回放，不读取封存比赛。

## 实际几何

maps/dota/world_physics.vmdl_c为2880676字节，PHYS资源块2878482字节。使用已有Source2Viewer CLI20、固定解码器SHA，解码为文本后严格读取静态单part、无骨架/绑定姿态、无球/胶囊/凸包/compound的已观察布局；不自行猜测KV3二进制压缩。

| 碰撞属性 | 顶点 | 三角面 | 已保留的属性线索 |
|---|---:|---:|---|
| default | 140724 | 288371 | 普通静态碰撞 |
| conditionallysolid #1 | 624 | 865 | npcclip、playerclip |
| conditionallysolid #2 | 2538 | 3905 | water |
| conditionallysolid #3 | 1219 | 1742 | window |
| 合计 | 145105 | 294883 | 不把这些类别合并成可走地面 |

顶点按明确的float32 XYZ读取，三角索引按uint32三元组读取，并核对字节长度、有限值、索引范围和各网格声明包围盒。数据中退化三角形为0，XY退化/近竖直面共742；这不是地图语义认证。

坐标保持physics_model_local_xyz。包围盒约X=-9472..9984、Y=-9472..10112、Z=-1200.5..3351.3，是碰撞几何范围，不是小地图边界、可走范围或安全放眼区域。世界放置变换尚未独立认证，不能因为分布像地图就给它标已校准。

## 声明的小地图窗口与地标

同一地图包的default_ents含两处dota_minimap_boundary，原点XY分别为(-9472,-9472)与(9472,9472)，零旋转、单位缩放；得到声明窗口18944×18944。另有world_bounds实体，其min=(-8448,-9472,0)、max=(8448,8448,1024)。三种范围互不混用。

它们还不同于旧Gem底图窗口18322和计划参考20864。这解释了为什么不能只搜一个“地图最大坐标”就全局替换：世界节点、碰撞体、小地图窗口和底图内容框是不同概念。新增asset-window-candidate.json进入既有VirtualMap候选契约，来源类型asset_extracted，仍unverified；未替换生产常量。

26个非塔地标声明包括12兵营、2遗迹、2瞭望塔、2莲花池、2泉水、2经验泉、2赏金符出生点、2强化符出生点。保留原实体序号、classname、targetname和XYZ；源实体原点不自动等于图标中心或地面接触点。这26条是来源点，不是26个已独立测量/留出的图像真值。

## 高度探针与图示

vertical_hits在XY处计算所有不同静态碰撞交点，可按明确属性索引过滤；不替用户选择最高或最低层为地面。共享三角边上的同层交点以0.0001单位量化去重，但保留命中三角形数量；竖直面不作为高度表面；超出结果上限保留省略数量，空命中不是高度0。

实际49个固定粗网格探针均有交点，其中9处有多层高度。不能把任何一个交点当作可行走高度、眼位高度或英雄脚底真值。悬崖、遮挡与条件碰撞必须保留分层信息，不应先压成单一高度图。

collision-overview.png绘制普通碰撞网格中236895个近水平三角形，按面均值Z排序着色，范围-128..768作显示截断。它是俯视几何示意，不是逐像素精确深度缓冲、纹理地图或认证地面高度图；没有隐藏被裁掉的原始XYZ，完整三角数据单独保存。

## 可复现入口

```powershell
python tools/extract_map_collision.py --game <安装目录>/game/dota --decoder <本机固定Source2Viewer-CLI.exe> --output diagnostics/<新目录>
python tools/extract_map_landmarks.py --game <安装目录>/game/dota --decoder <同一解码器> --output diagnostics/<另一新目录>
```

两工具只读安装包，解码两次并要求原字节一致，保存游戏构建、地图包/编译资源/解码器/导出文本SHA。输出只在Insights diagnostics，包含游戏导出与派生几何，全部Git忽略，不发布游戏资产。没有新CMD或Foresight选项。Dota运行时拒绝；中途启动则终止解码子进程；每次解码120秒、64MiB输出/1MiB错误上限，输出由文件stat监控，不seek子进程共用句柄。

首次探索导出有一处非法hex，严格提取器拒收，未删除字符或补字节。后续两次完整导出逐字节相同，进入正式工具后又重复验证两次；非法首次导出保留失败证据，不纳入网格。未把不稳定导出当作成功。不能仅凭监测方式变化断言首轮损坏的根因。

正式输出collision.json、meshes.npz和COMPLETE；地标输出landmarks.json、asset-window-candidate.json和COMPLETE。只有源文件、重复解码、所有网格校验及最后源复验通过后才生成COMPLETE。
