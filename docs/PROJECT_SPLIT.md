## 来源与恢复

`migration/source-manifest.json` 记录迁移前工作区的每个源文件SHA、首次导出SHA及原仓库HEAD。原工作区有未提交修改，因此HEAD不能独自代表迁移来源。包名从 dota2_economy 改为 dota2_insights，小地图离线模块成为其minimap子包。

英雄目录只提取静态名字/别名及ID函数，不复制采屏匹配器；离线路径门禁直接引用公开封存守卫，不再经由游戏记录器。声音读入与写出边界已按历史只读配置调整。后续修改以Git及最终核查清单为准，不能继续声称与初次导出SHA一致。

原始实验、失败回执、旧程序和数据未搬动、删除或打包进新Git历史。旧文档保留原日期，不伪装成本次已重新验证。

## 互通边界

助手生成关闭后的实战记录；分析项目读取其显式配置的路径。分析结果留在新项目，未来以版本化数据包发布。包需声明用途、来源、样本范围、补丁适用证据、构建、验证范围和失效条件；契约另行完成。

已验证期末装备不等于中途装备时间线通过；两个莲花集合点不等于全图标定通过。不能用一个总认证开关开启所有提示，也不能在拆仓时解锁封存比赛或自动激活未确认能力规则。
