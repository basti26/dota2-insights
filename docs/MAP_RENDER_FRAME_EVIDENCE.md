# 地图渲染与碰撞坐标对照

2026-11-06。目标是缩小虚拟地图与真实地图差异。本批只读本机游戏资产，继续解决静态几何坐标，不启动游戏、不读取新录像或联网。

## 结论

当前地图world.vwrld声明唯一世界节点原点为(0,0,0)，n0.vwnod中的124个指定地形模型实例使用单位放置变换。按数字地形块序号预先等距固定9块，选择在读取几何比较结果之前写入selection.json，不按匹配结果补选。

9块共有2523个逐块去重渲染顶点；2320个在0.01世界单位内存在普通碰撞顶点，覆盖声明小地图九宫格中的八区。共享顶点最大距离0.003232，未拟合旋转、平移、缩放来迎合碰撞。没有共享顶点的203个全部在普通碰撞模型观测包围盒之外，范围内未匹配为0；原始未匹配坐标完整保存，不能据此推断边界外的可走性。

这支持所抽样静态渲染/碰撞使用相同XYZ坐标系，比包围盒相似更直接；仍不是游戏客户端中的独立空间测量，不把整个physics模型运行时放置、高低坡可走性、眼位合法性、实时镜头或整图P2/P3勾选通过。原始CollisionMesh继续保留physics_model_local_xyz，不偷偷改成已认证世界高度。

## 数据路径与坐标配方

maps/dota/world.vwrld_c → 唯一节点原点；maps/dota/worldnodes/n0.vwnod_c → 地形资源和显式3×4单位变换；每个地形模型MDAT → 声明XYZ包围盒；已有固定SHA的Source2Viewer20 → 原始POSITION float32 glTF导出。

转换使用固定(gltf Z,X,Y)/0.0254配方，并与每块MDAT的六个包围盒分量比较（最大差0.002421世界单位）。没有调整配方来降低碰撞误差。仅支持已观察的单静态mesh、单buffer、近单位导出node、有限float32 POSITION；不支持的实例变换/布局拒收。模型位置与显示高度语义分开。

共享查找只检查固定0.02体素的邻近桶，实际欧氏距离<=0.01才记共享；不将较远最近点当同一个对象。重复位置逐块去重，不把2320称为2320个独立语义地标。渲染/碰撞同属一个资产构建，不能替代独立图像真值或最终留出集。

本机地图包SHA仍为8543569c3c661f69694a341603041bd32fde3599072d35a9301e68406d152a0f。world/node DATA、MDAT、glTF/bin均重复解码/导出并要求字节一致；原编译资源CRC、完整地图包、碰撞报告/网格SHA与输入退出复验保留。游戏中途启动则中断；导出单进程、30秒/32MiB限制，文本解码沿用120秒/64MiB限制。

## 实体原点高度探针

另在26个已知非塔实体原点XY处查询普通碰撞的所有静态交点：26处均有命中，14处实体Z与某个命中相差<=0.01（12兵营、2瞭望塔）。四处有多个量化高度，其中两处仅约0.0001数值差，另两处相差明显；全部命中仍保留。

反例同样保留：两处莲花池实体Z为98/101，碰撞命中128，相差30/27；两处遗迹差8/16，符点/经验泉等也有原点偏移。实体origin不是统一的地面接触点，不能用它直接纠正贴地高度；默认不选最高交点为地面。

## 实现与复现

- dota2_insights/map_render_geometry.py：世界节点/实例解析、固定九块选择、glTF坐标/包围盒核对、共享顶点/边界分类。
- tools/compare_map_render_geometry.py：本地有界提取、重复导出、同资产碰撞比较、完成收据。
- tools/extract_map_collision.py：只增加MDAT解码块白名单，原有PHYS逻辑不变。

```powershell
python tools/compare_map_render_geometry.py --game <安装目录>/game/dota --decoder <固定SHA的Source2Viewer-CLI.exe> --collision diagnostics/<已核验碰撞目录>/collision.json --output diagnostics/<全新输出目录>
```
