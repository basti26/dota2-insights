# 小地图镜头短边线离线试验

2026-11-06。原生镜头查询仍撤回；本试验不修改实战覆盖层或采集器。

新增离线研究模块`dota2_insights/minimap_edge_trial.py`：将小地图归一到380像素，取局部蓝青色残差；Hough只提出短线，使用原始选中像素重拟合，不通过闭运算制造断口像素。检查底边与左右边交点、实际端点邻近和裁边，保留多组候选而不擅自选一个。最多256个初始片段、每方向24条、12组假设；输出始终production_ready/outline_identity_verified/coordinate_accuracy_verified=false。门槛先由生成图固定，没有根据旧图结果放宽。

## 实际结果：不采用

对此前已准入的80张冻结原生图片，仅以生产者JSON提供的ROI和底图配准作数据输入，不导入Foresight源码。全部原图、输入JSON、清单和模块SHA前后重验。

- 80张全部底图配准已成功，原算法65张没有完整轮廓、15张采用默认上部范围，其中12张保留三条实测线。
- 新方法77张没有组成合格三边，3张产生唯一形状假设；3张全部未通过固定60度的条件平面检查。不是新增可用投影，不替换原方法。
- 片段组缺底边10张、缺左/右各1张，其余大多有零散线却不能组成共同轮廓。不能把这些片段直接拼成镜头；视觉抽看也有贴图边界、文字/图标遮挡，仅是开发观察，未逐图认证原因。
- 本机该次离线耗时中位26.24ms、P95 82.54ms，不代表游戏运行开销。没有部署或增加采样频率。

证据：`diagnostics/outline-failure-20261106/review.py`、`review.json`和24图ROI联系表`contact.jpg`。失败候选为frame-009、059、074，均以同一原因拒收。这个实验与原5个条件候选不能累计成精度结果。

5项生成测试覆盖正确轮廓、断口、缺边、裁边、多组竞争及无效输入；连同已有投影/接收专项52项通过，0失败/错误/跳过，源码稳定。收据`diagnostics/offline-tests/run-a997f45ad3ac/result.json`。合成测试通过不抵消实际材料试验失败。

## 下一步所需数据与失败边界

优先检查短时连续帧是否能分离移动的轮廓与固定地形/英雄图标。当前80张保存图，同双会话的74个相邻来源provider时间差最小60秒、最大858秒，0组在1.2秒以内；这只是GSI来源时间，不能冒充图片采集时间，但已经不能据此宣称存在同期连续图像证据。

后续Foresight应从**既有**15秒三帧窗口选取小地图裁片，保留原生ROI/图像尺寸、确切frame_id/采集UTC/单调时间、窗口编号/序号、地图包与配准来源SHA、公开比赛号与双会话、GSI来源ID、矩阵/缓存年龄/失败原因。无需新增截图调用或原生控制台命令。建议每60秒只留一个三帧裁片组、最多80组/会话、压缩总量独立上限和异步有界队列；缺帧/截断/超限必须留原因，不拿非同期图片拼组。这项**采集扩展尚未实现**，当前实战不会自动产生该新裁片组。

离线准入仍需闭合包与源指纹进出复验；同一窗口先检查图像运动、共同线段及竞争候选，任一证据不足就拒绝。通过连续性也不认证实际俯角、地形高度或眼位精度。先积累自然对局，无需用户专门开游戏。

## 自动留证后续实现更新

同日用户要求先完成数据记录，Foresight已采用更兼容的实现：从既有15秒三帧窗口每300秒留一组**原生完整画面**，仍80图/128MiB/两小时预算；未增加采屏或另设小图包。这样可在赛后同时核对英雄锚点及小地图，并离线裁图。缺失/间隔/跳序/限额留image_sampling原因。新包仍schema v2，image_interval_s=null，声明window_triplet/300秒/3帧计划；不能把声明当实际组齐全。新字段包含边缘本人候选、处理耗时、surface帧年龄及仅存档的白名单镜头位置配置观察。

两仓独立进程仅交换生成数据，原接收器review通过3帧闭合包、3图指纹核验；策略摘要现增加declared字段。29项Insights接收专项通过run-b6371a742bac。证据`diagnostics/ward-recording-ready-20261106/compatibility-review.json`。前文“采集扩展尚未实现”属于当时状态，本段取代它；真实连续画面/精度/游戏耗时仍未验证。未改旧资料或恢复原生查询。
